# Zego Dashboard

## Description
Zego Dashboard is an **Angular 18 admin panel** for the Zego ride-hailing platform.  
Through this dashboard, administrators can manage drivers, clients, trips, fares, and notifications, as well as monitor revenue and performance.

### Key Features

- **Driver Management**
  - Approve or reject new drivers
  - View driver status and activity
  - Block or unblock drivers
  - Full CRUD for driver accounts

- **Client Management**
  - View all clients
  - Manage client details
  - Full CRUD functionality

- **Trips Management**
  - Track all trips and view previous trips
  - Calculate fares per kilometer and peak time pricing
  - Real-time updates for active trips
  - Manage trip statuses and details

- **Revenue & Reports**
  - View revenue reports (daily, weekly, monthly)
  - Insights on trips, drivers, and client activity

- **Notifications**
  - Send push notifications to drivers or clients
  - Alerts for trip assignments, promotions, or updates

### Technologies Used
- Angular 18
- TypeScript
- HTML / CSS / SCSS
- RxJS
- Firebase (for real-time updates and notifications)

### Notes
- This repository contains the **UI and code structure** for the dashboard.  
- Any live data (drivers, clients, trips) are **connected to the real system** and are not included for security.  
- Safe to clone or review for learning or portfolio purposes.
